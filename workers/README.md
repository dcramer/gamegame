# GameGame Workers

LLM-powered board game assistant built on Cloudflare Workers.

## Quick Start

```bash
# First-time setup
make setup

# Start development server
make dev

# View all available commands
make help
```

## Setup Commands

| Command | Description |
|---------|-------------|
| `make setup` | Complete first-time setup (install + migrate + env check) |
| `make install` | Install dependencies only |
| `make setup-test` | Setup test environment with sample data |

## Development Commands

| Command | Description |
|---------|-------------|
| `make dev` | Start development server |
| `make test` | Run test suite |
| `make test-watch` | Run tests in watch mode |
| `make type-check` | Run TypeScript type checking |

## Database Commands

| Command | Description |

## CLI Commands

The CLI provides direct database access without requiring authentication:

```bash
# Games
pnpm cli games list                              # List all games
pnpm cli games create "Game Name"                # Create a game
pnpm cli games create "Arcs" --bgg-url="..."     # Create with BGG URL

# Resources (requires API/dev server running)
pnpm cli resources create <game-slug> <pdf-url>  # Add a resource
pnpm cli resources status <job-id>               # Check processing status

# Users
pnpm cli users create <email>                    # Create user
pnpm cli users create admin@example.com --admin  # Create admin user
pnpm cli users grant-admin <email>               # Grant admin privileges
pnpm cli users login-url <email>                 # Generate magic link

# Chat
pnpm cli ask <game-slug> "question"              # Ask a question
```

## Environment Setup

Create `.dev.vars` with your API keys:

```bash
OPENAI_API_KEY=sk-...
MISTRAL_API_KEY=...
JWT_SECRET=... # auto-generated by make setup
```

## Common Workflows

### Fresh Start
```bash
make reset      # Clean everything and start fresh
make games      # Verify empty database
pnpm cli games create "Catan"
make dev
```

### Database Issues
```bash
make db-reset   # Quick database reset without reinstalling
make games      # Verify reset worked
```

### Test Environment
```bash
make setup-test # Run comprehensive test environment setup
```

## Architecture

- **Stack**: Cloudflare Workers + D1 (SQLite) + Vectorize + R2
- **AI**: OpenAI GPT-4o + text-embedding-3-small
- **PDF**: Mistral OCR for extraction
- **Search**: Hybrid RRF (Vectorize semantic + D1 FTS5 full-text)

See project root `/CLAUDE.md` for detailed architecture documentation.
